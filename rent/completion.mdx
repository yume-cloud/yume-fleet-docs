# Завершение аренды

Завершение закрывает аренду. Начисления прекращаются, назначение закрывается, машина становится свободной в «Гараже». Долг водителя остаётся за ним. Вернуть аренду в работу из карточки нельзя, только новой арендой.

Кнопки «Вернуть машину» в шапке нет. Машину освобождают «Завершить» и «Заменить машину».

## Как завершить

1. Откройте карточку аренды. Кнопка **«Завершить»** стоит в шапке.
2. Окно спрашивает **«Завершить аренду?»**.
3. Выберите причину: **«Уехал с долгом»** или **«Просто закончил»**. Без причины кнопка не нажимается.
4. Выберите сегодняшний день: **«Начислить — машина была у водителя сегодня»** или **«Не начислять — день не берём»**. Без выбора кнопка не нажимается.
5. Нажмите **«Да, завершить»**. **«Отмена»** закрывает окно, аренда не меняется.

Пока аренда закрыта, действия недоступны.

## Депозит

Возврат депозита — отдельная кнопка, не шаг завершения. В правой рейке блок **«Депозит водителя»**. Кнопка **«Вернуть депозит водителю»** есть, только когда на кошельке водителя есть деньги. Подтверждение спрашивает сумму. Долг из депозита не удерживается.

## Выкуп

На выкупе кнопки **«Заменить машину»** нет: водитель выкупает конкретную машину. Завершение идёт той же кнопкой **«Завершить»**.
